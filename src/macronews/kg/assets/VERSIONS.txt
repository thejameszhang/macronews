Vendoring: the bundle's single trailing `export{...}` is rewritten to
`globalThis.cosmos={...}` so it loads as a classic script (see the file's
last line). Additionally, `</` and `<!--` are escaped to `<\/` and `<\!--`
(semantics-neutral inside the bundle's JS string literals) so the inlined
bundle cannot break out of the host page's <script> tag: cosmos bundles
DOMPurify ("<!-->", "<!---->") and an FPS-monitor "</style>" string, and a
raw `<!--`/`</...>` flips the HTML tokenizer into script-data-escaped state,
dumping the rest of the bundle as visible page text. Re-vendor by re-running
Task 1 of the cosmos renderer plan (which applies both rewrites).
